# Warm Eddy Event Reporter

A tiny, clean, open-source demo for AI-assisted physical oceanography.

This project generates a fully synthetic sea-surface temperature anomaly field,
detects a warm eddy event with a simple transparent algorithm, and exports a PNG
figure plus a Markdown event report.

The repository is designed to be safe for public sharing:

- No private research code.
- No real NetCDF files.
- No thesis material.
- No local machine paths.
- Only synthetic demo data generated by the scripts in this repository.

## Why This Exists

Ocean scientists often move from gridded data to figures, event summaries, and
paper-ready descriptions. This demo shows the smallest useful version of that
workflow:

1. Create synthetic demo data.
2. Detect a warm-core eddy.
3. Export a figure and a reproducible Markdown report.
4. Prepare a prompt template for future LLM-assisted scientific summaries.

Future token support would be used for AI-assisted interpretation of ocean
events, figure captions, multi-date evolution summaries, and reproducible
research writing. The current open-source version does not call any model API.

## Quick Start

Requires Python 3.10 or newer. No third-party packages are required.

```powershell
python generate_sample.py
python detect_eddy.py
python plot_report.py
```

Generated files:

- `data/synthetic_warm_eddy_sst_anomaly.csv`
- `data/synthetic_warm_eddy_metadata.json`
- `outputs/synthetic_warm_eddy_detection.json`
- `outputs/synthetic_warm_eddy_map.png`
- `outputs/synthetic_warm_eddy_report.md`

## Run Tests

```powershell
python -m unittest discover -s tests
```

The tests use temporary synthetic data and do not require network access or
third-party packages.

## Script Overview

### `generate_sample.py`

Creates a synthetic sea-surface temperature anomaly field. The field contains a
Gaussian warm-core eddy, a weak background gradient, a smooth wave signal, and
small deterministic noise.

### `detect_eddy.py`

Finds the warmest grid point, estimates a border-based background value, extracts
the connected half-maximum warm region around the peak, and reports approximate
center, intensity, radius, and area.

### `plot_report.py`

Writes a dependency-free PNG heatmap and a Markdown event report. The PNG writer
uses only the Python standard library.

### `prompts/summary_prompt.md`

Provides a prompt template for future LLM-assisted scientific narration. It is
included as design material only; the scripts do not call an API.

## Example Research Story

The synthetic warm eddy can be used to demonstrate how an AI copilot might help
with:

- explaining detected eddy metrics in plain language;
- drafting figure captions;
- comparing event properties across dates;
- turning reproducible diagnostics into a short scientific report.

## Safety Note

All files produced by this project are generated from synthetic demo data. Do not
mix private data or unpublished research outputs into this repository unless you
intentionally want to publish them.
